# GitHub Issue Template 설치 방법

이 폴더는 연구실 구성원이 자신의 GitHub 저장소에 공통 Issue Template을 적용하기 위한 배포 패키지입니다.

## 설치

1. 자신의 프로젝트 저장소를 컴퓨터에 내려받습니다.
2. Finder에서 `Command + Shift + .`을 눌러 숨김 파일을 표시합니다.
3. 이 폴더 안의 `.github` 폴더를 자신의 저장소 최상위 폴더로 복사합니다.
4. 다음 파일을 GitHub에 반영합니다.

```bash
git add .github/ISSUE_TEMPLATE
git commit -m "chore: 연구실 공용 Issue Template 적용"
git push
```

5. 기본 브랜치에 반영한 후 다음 주소에서 확인합니다.

```text
https://github.com/자신의계정/저장소이름/issues/new/choose
```

## 포함된 양식

| 양식 | 용도 |
| --- | --- |
| 연구 업무 | 연구·조사 업무와 일정 관리 |
| 테스트 | 기능 및 연구 결과 검증 |
| 오류 보고 | 오류 재현과 해결 과정 기록 |
| 문서 작성 | 문서 및 발표 자료 작성 |
| 교수님 요청사항 | 요청 내용과 수행 결과 관리 |

## 주의사항

- 대상 저장소에 기존 `.github/ISSUE_TEMPLATE` 폴더가 있다면 덮어쓰기 전에 내용을 확인합니다.
- Template은 대상 저장소의 기본 브랜치에 반영되어야 표시됩니다.
- 비공개 저장소에서는 해당 저장소에 접근 권한이 있는 사람만 사용할 수 있습니다.
