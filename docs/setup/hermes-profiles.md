# Hermes 프로필 이해하기

## 세 가지 이름은 서로 다릅니다

| 화면에 보이는 이름 | 의미 |
|---|---|
| Orca 계정 | Orca 앱에 로그인한 개인 계정 |
| 원격 서버의 OS 사용자 | worker03에서 명령을 실행하는 Linux 사용자 |
| Hermes 프로필 | 대화, 설정, 플러그인을 분리하는 Hermes 작업 공간 |

Orca 사이드바의 작업 아래에 보이는 `hyunsoung` 같은 표시는 보통 **원격 서버 표시 이름**입니다. 현재 Linux 사용자나 Hermes 프로필이라는 뜻은 아닙니다.

## 개인 프로필로 Hermes 열기

```bash
hermes --profile hyunsoung
```

프로필 데이터는 서버 디스크에 저장되므로 VPN이나 Mac을 껐다 켜도 사라지지 않습니다. 하지만 새 Hermes 실행 때 어떤 프로필을 사용할지는 실행 명령과 Orca 설정에 따라 달라질 수 있습니다.

## 현재 상태 확인

Hermes 안에서 다음을 확인합니다.

```text
/status
```

터미널의 Linux 사용자는 다음으로 확인합니다.

```bash
whoami
```

## 공용 서버에서의 주의점

- 프로필이 달라도 같은 Linux 계정을 공유하면 운영체제 수준에서 완전히 격리된 것은 아닙니다.
- 프로필별 설정과 플러그인은 다른 프로필에 자동 적용되지 않을 수 있습니다.
- 설치·업데이트할 때 항상 `--profile hyunsoung`을 명시하면 실수를 줄일 수 있습니다.
- 다른 연구원의 프로필 폴더나 실행 중인 세션을 수정하지 않습니다.
