# 공용 서버 안전 수칙

## 저장소에 올리지 않는 정보

- 서버의 실제 내부 IP
- OpenVPN 설정 파일과 인증 정보
- SSH 개인 키와 실제 개인 키 경로
- 계정 비밀번호와 API 토큰
- `orca://pair?code=...` 액세스 링크
- 민감한 터미널·설정 화면 캡처

예시는 `<WORKER03_IP>`, `<SSH_USER>`, `<PRIVATE_KEY_FILE>`처럼 표시합니다.

## 프로세스 종료 원칙

1. `whoami`로 현재 OS 사용자를 확인합니다.
2. PID, 부모 PID, 실행 시간, TTY, 전체 명령을 함께 확인합니다.
3. 내 세션과 정확히 일치하는 PID 하나만 종료합니다.
4. `killall`, 광범위한 `pkill`, 다른 사용자의 PID 종료는 피합니다.

공용 Linux 계정을 함께 쓰는 환경에서는 같은 계정의 다른 연구원 프로세스도 보일 수 있으므로 특히 주의합니다.

## Hermes 실행 원칙

- 개인 프로필을 항상 명시합니다: `hermes --profile hyunsoung`
- 자동 실행 권한이 큰 모드는 필요한 작업에서만 사용합니다.
- 중요한 파일을 수정하기 전에는 Git 상태와 작업 경로를 확인합니다.
- 작업을 끝낼 때 `/quit`으로 세션을 정상 종료합니다.
