# 플러그인 보안 검사에서 설치가 차단될 때

## 의미

`Security scan blocked plugin install`은 설치 파일에서 주의가 필요한 항목을 발견해 사용자 확인 없이 설치하지 않았다는 뜻입니다. 이 메시지만으로 악성 플러그인이라고 단정할 수는 없지만, 공용 서버에서는 검토 없이 강제 설치하면 안 됩니다.

## 처리 순서

1. 이미 해당 프로필에 설치되어 있는지 확인합니다.
2. 설치 출처, 저장소 소유자, 요청 권한과 검사 경고 내용을 확인합니다.
3. 공용 서버 정책이 있다면 관리자 승인을 받습니다.
4. 신뢰할 수 있다고 확인한 경우에만 경고 화면이 안내하는 승인 또는 강제 설치 옵션을 사용합니다.
5. 설치 후 Hermes를 재시작하고 활성화 상태를 확인합니다.

## 주의사항

- 경고를 피하려고 서버 전체의 보안 검사를 끄지 않습니다.
- 출처가 불명확한 플러그인에 강제 옵션을 사용하지 않습니다.
- 비밀번호, 토큰, SSH 키를 플러그인 설정에 그대로 넣지 않습니다.
- 이미 정상 설치된 플러그인은 문제 해결을 위해 무작정 재설치하지 않습니다.
